## 💻 Local Development

```bash
# 1. Clone repository
git clone https://github.com/VasuRachhadiya/vasurachhadiya.git
cd vasurachhadiya

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build for production
npm run build
```

---

## 🌐 Deploy to Vercel

This repository includes a pre-configured `vercel.json` for seamless Vite deployment.
1. Sign in to [vercel.com](https://vercel.com) with GitHub.
2. Import repository `vasurachhadiya`.
3. Framework Preset: **Vite** (default).
4. Click **Deploy**.
